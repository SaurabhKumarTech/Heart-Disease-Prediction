# Heart Disease Prediction

## Overview
A machine learning project that predicts the possibility of heart disease using a K-Nearest Neighbors (KNN) classification model. The model is integrated with a Streamlit web application.
## Technologies Used
- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
## Input Features
- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope
